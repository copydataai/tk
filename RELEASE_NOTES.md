# Release notes

## Local Speech profiles

- The bundled Balanced Dictation and Best quality Reading defaults are unchanged and continue to work offline.
- Optional Fast and Best quality Dictation profiles and a Lower memory Reading profile require an explicit internet download from their pinned source.
- Downloading a profile does not select it. An explicit selection applies to the next Dictation, Read Aloud, or Voice Preview request.
- Dictation and reading remain local after any requested profile download; there is no cloud fallback, catalog request, telemetry, or silent model update.
